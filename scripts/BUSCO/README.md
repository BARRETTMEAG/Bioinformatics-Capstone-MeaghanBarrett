BUSCO Overview:

This folder contains files for downloading all the way to getting statistics for completeness.

1st - Use the download_genomes.sh script to be able to get the complete genomes (assemblies).

2nd - Use run_buscho.sh to generate the filtered genome groups (genomes_raw).

3rd - Use generate_assembly_stats.sh and parse_busco_summaries.sh to be able to create a statistics summary for every selected Salmonella group.
